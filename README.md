# techshop — магазин техники

Контрольная работа №4: «JavaScript: интерактивность, DOM, события, формы и валидация».

[Открыть сайт](https://69mirea-anime69.github.io/kr4-js-shop/)

## Основа

Проект продолжает [КР №3](https://github.com/69mirea-anime69/kr3-responsive-shop): сохранены многостраничная структура, отдельный responsive.css, семантическая навигация, skip-link, работа с клавиатурой и подход к адаптивным сеткам. Вёрстка значительно переработана под магазин компьютерной техники. Bootstrap, React, jQuery и другие библиотеки в сайте не используются.

Названия, характеристики и цены товаров — учебные примеры, не реальные предложения производителей. Настоящей отправки данных и оплаты нет.

## Данные и DOM

В `data.js` 10 объектов с одинаковыми полями: `id`, `title`, `category`, `price`, `isAvailable`, `image`, `description`, `badge`, `specs`. Id уникальны, цены — числа. У одного товара нет наличия: добавить его в корзину нельзя.

Карточки создаются функцией `productCard()` через `createElement()`. Классы задаются через `classList`, текст — через `textContent`, готовые узлы добавляются через `append()`. Перед перерисовкой используется `replaceChildren()`.

В проекте нет `innerHTML`, `alert()` и inline-обработчиков. Пользовательский ввод и сведения из localStorage не превращаются в HTML. Хранилище проверяется: принимаются известные id доступных товаров и целые количества от 1 до 99; повреждённый JSON не ломает страницу. Данные формы в хранилище не записываются.

Скрипты подключены с defer в порядке: данные → корзина → каталог → модальное окно → валидация → инициализация. Это обычные JS-файлы без сборщика; функции объявлены до момента их вызова. Перед работой с элементами отдельных страниц проверяется их наличие.

## Каталог

- Поиск по части названия без учёта регистра и пробелов по краям, событие `input`.
- Категория, наличие и избранное, событие `change`.
- Ограничение максимальной цены, событие `input`.
- Сортировка по возрастанию/убыванию цены и названию. Сортируется копия массива, исходный порядок сохраняется.
- Все условия работают совместно.
- Счётчик результатов, пустое состояние и кнопка сброса.
- Переходы из категорий на главной сразу устанавливают фильтр.

## Доработки

- Корзина: добавление, удаление, изменение количества и общий счётчик в шапке.
- Сумма товаров считается через reduce.
- Корзина, избранное и состояние промокода сохраняются в localStorage.
- Сердечко избранного меняет состояние и доступно с клавиатуры.
- START10 даёт скидку 10% на товары с округлением до целого рубля.
- Самовывоз бесплатный. Доставка — 490 ₽, от 10 000 ₽ после скидки — бесплатно.
- Быстрый просмотр в нативном dialog. Escape закрывает окно, фокус возвращается к кнопке, которая его открыла.
- Страница product.html показывает данные выбранного товара. Для неизвестного id есть понятное пустое состояние.
- После проверки формы имитируется короткая подготовка заявки; кнопка временно блокируется, результат выводится на странице. Корзина после подготовки не очищается: её можно исправить.

## Валидация

Проверяются имя (минимум два символа после trim), непустой e-mail через браузерный validity, российский телефон (10 цифр или 11 с 7/8), согласие и непустая корзина. Для курьерской доставки обязателен адрес минимум из 10 символов. Пробелы, скобки и дефисы в телефоне допускаются.

Ошибки показываются рядом с полями через textContent. Поля связаны с ошибками через aria-describedby, ошибочные поля получают aria-invalid. Фокус переводится на первое ошибочное поле. Результат подготовки выводится через role=status. Клиентская проверка не заменяет серверную — серверной части в этой КР нет.

## Запуск

Откройте index.html или запустите в папке проекта:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000. Установка npm-пакетов для сайта не нужна. При запуске через file:// поведение localStorage может зависеть от браузера, поэтому для проверки сохранения рекомендуется HTTP-сервер.

## Что проверено

- Все 6 страниц: ширины 360, 430, 768, 1024, 1440 px. Горизонтального скролла страницы нет.
- Консоль браузера: критических ошибок не обнаружено.
- Поиск «КЛАВИАТУРА» — два результата; сочетание с категорией «Аудио» — пустой результат. Сброс возвращает 10 товаров.
- Сортировка от дешёвых: первая мышь за 3290 ₽, последний ноутбук за 94990 ₽.
- Добавление в избранное и фильтрация избранного.
- Две мыши Wireless Pro: 6580 ₽. START10: скидка 658 ₽, итог 5922 ₽. С доставкой: 6412 ₽. Сумма и корзина сохраняются при перезагрузке.
- Пустая форма, отсутствующее согласие и отсутствие адреса при доставке показывают ошибки.
- Корректная форма показывает подготовленную заявку без отправки на сервер.
- Строка `<img src=x onerror=alert(1)>` в имени выводится обычным текстом, изображение не создаётся и код не выполняется.
- Escape закрывает быстрый просмотр и возвращает фокус к исходной кнопке.

Чтобы повторить проверку, начните с пустой корзины или удалите ключи sborka-cart, sborka-favorites и sborka-promo в DevTools → Application → Local Storage только для адреса этого сайта.
